# MVSplat360 Project Page

This branch holds the static project page for **MVSplat360: Feed-Forward 360° Scene Synthesis from Sparse Views** (NeurIPS 2024).

The page is published by GitHub Pages from this `gh-pages` branch and lives at <https://donydchen.github.io/mvsplat360/>.

Paper: <https://arxiv.org/abs/2411.04924>

The research code lives on the `main` branch of this same repository.

## Notes

This is a plain HTML/CSS/JS site. The empty `.nojekyll` file at the root tells GitHub Pages to skip Jekyll processing and serve the files exactly as they are.

For feedback or questions, contact [Donny](http://donydchen.github.io/).
